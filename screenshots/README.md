# 📸 SmartLoan Screenshots

## How to Add Screenshots

1. **Run the application**:
   ```bash
   python simple_app.py
   ```

2. **Take screenshots of these pages**:
   - Dashboard: `http://localhost:5000`
   - Loan Application: `http://localhost:5000/apply`
   - Customer Management: `http://localhost:5000/customers`
   - Loan Management: `http://localhost:5000/loans`

3. **Save screenshots as**:
   - `dashboard.png` - Main dashboard with metrics and charts
   - `loan-application.png` - Loan application form
   - `customer-management.png` - Customer list and management
   - `loan-management.png` - Loan portfolio view
   - `risk-assessment.png` - Risk calculation results

4. **Screenshot Tips**:
   - Use full browser window (1920x1080 recommended)
   - Include browser address bar to show it's a real app
   - Capture with sample data visible
   - Use Chrome/Edge for consistent appearance
